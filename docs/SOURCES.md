## Ramp API facts used above (Job 1 detail)

All from https://docs.ramp.com/llms-api.txt and https://docs.ramp.com/openapi/developer-api.json, checked 2026-11-10. Reference pages: https://docs.ramp.com/developer-api/v1/api/bills and https://docs.ramp.com/developer-api/v1/api/vendors.

- `PATCH /developer/v1/bills/{bill_id}`: "Only approved bills can be updated." It accepts `payment_date` (nullable; "Set to null to unschedule the payment") and `payment_method`. It does not accept `EARLY_PAYMENT_DISCOUNT`.
- `POST /developer/v1/bills/{bill_id}/hold` and `POST /developer/v1/bills/{bill_id}/release` carry `x-beta: true` in OpenAPI.
- Custom Records API (`/developer/v1/custom-records/...`). Guide header: "Custom Records API is in Beta".
